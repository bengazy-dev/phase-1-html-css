# Bengazy Dev Portfolio

A personal portfolio website built from scratch using HTML and CSS.

## Live Site

[View Live](https://bengazy-dev.github.io/phase-1-html-css)

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Google Fonts (Poppins)

## Features

- Responsive navigation bar
- Skills section with pill badges
- Projects section with CSS Grid layout
- Dark theme design
- Anchor link navigation
